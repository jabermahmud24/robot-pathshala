# রোবট পাঠশালা · Robot Pathshala

**বাংলায় খেলতে খেলতে রোবটিক্স শেখা।** ৭ থেকে ১৮ বছরের শিক্ষার্থীদের জন্য সম্পূর্ণ বিনামূল্যের একটি ওয়েবসাইট ও অ্যাপ, যা ইন্টারনেট ছাড়াও চলে।

**Learn robotics through play, in Bangla and English.** A free website and installable app for students aged 7 to 18 in Bangladesh. It works offline.

👉 **https://jabermahmud24.github.io/robot-pathshala/** (বাংলা)
👉 **https://jabermahmud24.github.io/robot-pathshala/?lang=en** (English)

## কী কী আছে · What's inside

- **রোবটের ভেতর · Inside a robot:** tap a robot's sensors, brain, motors, wheels, battery and antenna to learn what each does, at three reading levels (ages 7–10, 11–14, 15–18).
- **টের পাওয়া, ভাবা, কাজ করা · Sense, think, act:** a live simulator of how a robot stops before a wall.
- **১০০টি রোবট · 100 robots:** humanoids, Mars rovers, farm drones, surgical robots and more, each with a blueprint of its insides, an easy comparison and a fun fact.
- **কোডিং · Coding maze:** 10 levels of block coding that teach sequences, loops and if/else.
- **মিশন গেম · Mission game:** build a robot within a budget for missions like a flood rescue in Sylhet or counting tigers in the Sundarbans.
- **রোবুর অভিযান · Robu's story**, **daily question**, **quiz**, **read-aloud** and a **certificate**.

## For teachers and parents

Everything runs in the browser, with no sign-up, no ads and no personal data collected. Progress is saved only on the child's own device. Some information may not be fully accurate; please check important facts with a trusted source.

Plain HTML, CSS and JavaScript with no build step.

# রোবট পাঠশালা (Robot Pathshala)

An interactive Bengali website where kids aged 7–18 in Bangladesh learn how robots work: a tappable robot body explorer, a sense–think–act simulator, a catalogue of 100 robots, a build-your-own-robot game and a quiz.

Plain HTML, CSS and JavaScript with no build step. Live at https://jabermahmud24.github.io/robot-pathshala/
